# eezolabs-site

Static site for [eezolabs.com](https://eezolabs.com) — Eezo Labs.

Hosted on GitHub Pages.

## Files
- `index.html` — homepage
- `rebill-privacy.html` — Rebill privacy policy
- `billkeep-privacy.html` — BillKeep privacy policy
- `logo.png` — full Eezo Labs logo (mark + wordmark, transparent)
- `logo-mark.png` — mark only, transparent (for app icons / social avatars)
- `favicon.png` — small mark for browser tabs
- `rebill-icon.png` — Rebill app icon
- `billkeep-icon.png` — BillKeep app icon
- `CNAME` — GitHub Pages custom domain config
